# Тактические обозначения

`/symbols` — описание принципов, поиск и каталог по материалу http://lemur59.ru/node/427.
Материал описывает Советскую Армию, не является полным перечнем знаков и не подтверждает стандарт ВС РК.

## Реализовано

- Общий переключатель НАТО / Казахстан для карты, списка соединений, инспектора и справочника.
- Настройка `dala:symbol-standard:v1` сохраняется отдельно от сценария; синхронизируется между вкладками и работает в памяти при недоступном localStorage.
- 12 игровых типов, две стороны, семь уровней подразделений. Для воздушных средств НАТО уровень указан текстом, поскольку используется знак воздушного объекта, а не наземного подразделения.
- НАТО: milsymbol 3.0.4, режим APP6, буквенные SIDC. Это выбранный набор, не заявление о полной реализации актуальной редакции APP-6.
- Казахстан: явно обозначенная учебная адаптация; собственные SVG по принципам источника. БПЛА — игровой знак, отсутствующий в статье. Нужна сверка с документом ВС РК.
- 230 записей в 10 разделах: 12 игровых типов и 218 позиций для будущего расширения. Варианты исходной статьи перечислены отдельно там, где они имеют отдельное назначение. Это каталог, не 230 готовых графических символа.
- Три локальные обзорные таблицы из материала: `public/reference/tactical-signs-*.jpg`. Источники: `http://lemur59.ru/sites/default/files/images/2062.jpg`, `2063.jpg`, `2064.jpg`. Ссылки на GIF на army.armor.kiev.ua, используемые далее в статье, возвращают страницу 404 при проверке 22.09.2026.

## Расширение

Реестр находится в `src/lib/symbol-catalog.ts`, отрисовка — в `src/lib/symbology.ts`.
Будущие записи не добавляются к типам игрового баланса: точки, линии и площади требуют отдельных слоёв и механики размещения. Для добавления нового графического символа нужны проверенный рисунок, соответствие SIDC (если оно существует), геометрия и источник. Не заменять отсутствующее соответствие общим знаком категории.

До появления сохранённых объектов каталога последовательные ID допустимы; при введении сохранения закрепить ID миграцией и не менять их при перестановке записей.
