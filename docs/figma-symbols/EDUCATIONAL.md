# Учебные образцы

Пользователь разрешил отдельно отрисовывать учебные образцы, если официальный источник ВС РК не найден.

## Стилистика и ТЗ

- Самостоятельный раздел Figma «DALA / Учебные образцы».
- Редактируемые векторные компоненты, без растровых вставок.
- Светлый фон, тонкие контуры, подписи Inter, сетка из четырёх карточек.
- На каждой карточке название, источник и «Статус ВС РК не подтверждён».
- 13 существующих знаков сохраняют геометрию и цвета DALA.
- 10 исторических образцов перерисованы по `public/reference/tactical-signs-1.jpg`; первоисточник таблицы указан в приложении как http://lemur59.ru/node/427. Официальность и актуальность таблицы не установлены.
- Миномёт соответствует изображённому в таблице варианту до 120 мм.
- Официальный статус в `registry.json` остаётся `pending`.

## Промпт для переноса

Создай в файле dala отдельный раздел «DALA / Учебные образцы». Используй SVG из educational-samples.json как исходную геометрию. Каждый образец оформи отдельным компонентом с описанием источника. Размести компоненты в каталоге из четырёх колонок; добавь явную отметку об отсутствии подтверждённого статуса ВС РК. Сохрани существующий каталог. Проверь итог скриншотом и запиши идентификаторы компонентов.

## Подготовленные материалы

- `educational-svg/`: 23 SVG.
- `educational-samples.json`: названия, источники и исходная графика.
- `educational-preview.html`: локальный визуальный каталог.
- `import-educational.js`: сценарий переноса через Desktop Bridge; вместо `__SAMPLES__` подставляется массив samples.

Готовность локальных SVG не означает, что они уже перенесены в Figma. Фактический результат переноса фиксируется отдельно в `educational-figma-state.json`.
